# Slugger : le token de fin de slug

Slugger génère des identifiants lisibles à partir des mots d'un thème, comme les noms de conteneurs Docker. Un slug peut se terminer par un **token** : quelques caractères tirés au hasard, décimaux ou hexadécimaux, qui n'apparaissent qu'une partie du temps.

```
neon-samurai
neon-samurai-4821
```
